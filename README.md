# TP_DevOps OLIVIER Matéo

## Tetris

Le but de ce projet est de faire une page web implémentant le jeu du Tetris. 
Il n'est pas question de faire un jeu très avancé mais surtout de mettre en oeuvre les différentes méthodes vu lors des scéances de TD pour ce projet.


## Lien avec le cours

Image docker pour le jeu/BDD en MySQL pour stocker les scores.

## Installation

Pour utiliser le jeu en local, il faut cloner le projet et executer la commande : docker compose up --build

Le volume alloué pour le stockage des scores se trouve au niveau de /data dans l'image db.
